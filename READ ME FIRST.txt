====================================
 Tiger QuickLook
====================================

Preview a file by pressing the Space bar, the way Leopard's
Quick Look does. For Mac OS X 10.4 Tiger.


USE IT
------
1. Unzip this file.
2. Double-click "TigerQuickLook".
3. In the Finder, click a file once and press the Space bar.
   A preview opens. Press Space again to close it.
   Arrow keys show the next / previous file.


IF SPACE DOES NOTHING
---------------------
Turn on one checkbox:

   Apple menu > System Preferences > Universal Access >
   "Enable access for assistive devices"

Then quit Tiger QuickLook (the "QL" menu at the top-right of
your screen, next to the clock) and open it again.


KEEP IT RUNNING
---------------
System Preferences > Accounts > Login Items, and add
TigerQuickLook. Now it starts every time you log in.
The "QL" at the top-right means it is running.


BUILD IT YOURSELF (optional)
----------------------------
You do not need this to use the app. The source code is here:
https://github.com/watermark-hd/tiger-quicklook


------------------------------------
Works with images, text and code files, and Word / Excel /
PowerPoint / OpenOffice documents (text only - just enough to
see what the file is). Other files do nothing.

If Space types a space while you are renaming a file in the
Finder, press Esc.

After you update, quit the old copy first, then open the new
one.
